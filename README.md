# ドメモ

1人1台のスマホ/PCでドメモを遊ぶWebアプリです。

- **公開版**：Render に置いて、部屋リンクを友達に送って遊ぶ
- **LAN版**：Mac で起動して、同じWi-Fiの端末から遊ぶ（ネット不要）

どちらも同じコードで動きます。

## 遊び方

1. トップで「部屋を作る」を押す
2. 名前を入れて参加 → ロビーの「招待リンクを送る」でLINEなどに共有（QRでも可）
3. 2〜5人そろったら、誰かが「ゲーム開始」
4. 自分の番に、自分のタイルにあると思う数字（1〜7）を押す
   - 当たり：自分のタイルが1枚表になる。2〜3人のときは続けて宣言できる（「ここで手番を終える」で交代も可）
   - はずれ：次の人の番
5. 自分のタイルを全部当てた人から順に上がり（1位、2位…）。終了時には伏せタイルも公開されます

**ロビーで選べる設定**（部屋の誰が変えても全員に反映）
- 1ターンに当てられる枚数：1枚／2枚／3枚／無制限（公式）。2〜3人のときだけ効きます
- 終了条件：最下位が決まるまで（上がった人は抜けて観戦）／1位が出たら終了
- 宣言ログ：全部表示／直前の1手番だけ（それより前は記憶勝負。サーバーが送らないので覗けません）
- 持ち時間（1手番）：なし／15秒／30秒／60秒。時間切れは「はずれ」扱い。リーチの人の番で半分を切ると「ざわ…ざわ…」

| 人数 | 1人の枚数 | 伏せ | 場に公開 | 正解後の連続宣言 |
|---|---|---|---|---|
| 2 | 7 | 7 | 7 | できる |
| 3 | 7 | 7 | 0 | できる |
| 4 | 5 | 4 | 4 | できない |
| 5 | 4 | 4 | 4 | できない |

**決まった仲間で毎回同じ部屋を使いたいとき**：`https://（公開URL）/?room=KOTA` のように、英数字4〜8文字の好きなコードをURLに付けて共有すれば、いつでもその部屋で集まれます。

## 公開版（Render）の注意

- しばらく（15分）誰も使わないとサーバーが眠ります。次に開いたとき、表示まで1分ほどかかります。遊ぶ前に誰か1人が開いておけばOKです。
- サーバーが眠ったり更新されたりすると、遊んでいる途中の部屋は消えます（リンクはそのまま使えます）。
- リンク（部屋コード）を知っている人は誰でも入れます。

## LAN版（Mac で起動）

初回だけ：ターミナルで `node -v` を実行し、`v18` 以上が出なければ https://nodejs.org から LTS 版を入れてください。

```bash
cd ~/Downloads/domemo   # フォルダの場所に合わせて変える
npm install             # 初回のみ
npm start
```

- ターミナルに出るQRをスマホで読み、トップから部屋を作ります。
- 初回に「"node" への受信接続を許可しますか？」と出たら **許可** を押します。
- 終了は `control + C`。

## 困ったとき

- **LAN版でスマホから開けない**：Macとスマホが同じWi-Fiか確認。大学・会社・ゲストWi-Fiは端末同士の通信を禁止していることがあります。
- **画面が消えて切れた**：同じリンクを開き直せば同じ席に戻れます。
- **ポート3000が使われている**：`PORT=3001 npm start`。
- **動作確認**：`npm test` でルールのテストが走ります。

## しくみ（メモ）

- ゲームの正しい状態はサーバーだけが持ち、各端末には「その人が見てよい情報」だけを送ります（`game.js` の `viewFor`）。開発者ツールを見ても自分の数字は分かりません。
- 自分の手札は「当てたもの → 未公開」の順に表示します。昇順のままだと、表になったタイルの位置から残りの数字の大小が推測できてしまうためです。
- 部屋は URL の `?room=コード` で区別し、初めて開かれたときに作られます。全員いなくなって30分たつと消えます。

| ファイル | 役割 |
|---|---|
| `game.js` | ルール（配牌・宣言判定・勝利判定・プレイヤー別の表示情報） |
| `server.js` | 通信（Socket.IO）、部屋管理、参加・再接続、QR |
| `public/` | 画面（HTML / CSS / JS） |
| `test.js` | ルールのテスト |
